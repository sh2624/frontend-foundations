## Week 1–2 회고 (DAY 1~11)

### 1. 학습 및 구현

- `map`, `filter`, `reduce`, `sort` 등 배열 메서드 조합 학습
- 식당 검색·추천 기능과 주문 금액 계산 로직 구현
- 조건별 함수 분리와 원본 배열 불변성 유지 연습

### 2. 어려웠던 점

- `splice()`의 반환값과 원본 배열 변경을 혼동함
- 객체 참조와 얕은 복사의 차이를 이해하는 데 어려움을 겪음
- 실제 버그를 발견하지 못하는 테스트 코드를 작성함
- 시간 복잡도 계산에서 반복 실행과 중첩 실행을 혼동함

### 3. 개선한 점

- 원본 배열 변경을 방지하기 위해 복사 후 정렬하는 방식 적용
- 여러 조건의 필터링과 다중 기준 정렬을 독립적으로 구현
- 함수 실행 결과가 아닌 사전에 정의한 기대값과 비교하도록 테스트 개선

### 4. 다음 목표

- 테스트 케이스의 검증력 높이기
- 시간 복잡도 분석 연습
- DOM 조작과 이벤트 처리 학습
